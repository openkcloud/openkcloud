code-server IDE 구현 완료

#4 포털

사용자 / 관리자 포털 목업 v2.0 반영 완료

  • 범위 IaaS(OpenStack) · PaaS(K8s) 자원, AI 노트북, 마켓플레이스, 옵저버빌리티, IAM을 한 포털로
  • 진행 목업 v1.0(6/4) → ETRI 검토 · 회의 · 워크샵 반영 v2.0(9/15) → 10월 초 실구현 착수
  • 통합 시범서비스 kcloud-svc · 이노그리드 Monitor API v2와 연동(2026 통합 목표)
#1 인증 · 인가

Keycloak SSO · RBAC

  • Keycloak OIDC/OAuth2 엔진 · JWT 토큰 · role/scope — 5개 흐름(로컬 · Client Credentials · Device Grant(CLI) · SSO · Federated LDAP/AD)
  • 2단계 인가 API Gateway(JWT 검증 · rate limit · WAF · 로깅) → Platform Control Plane(OPA 2차 인가, Quota Engine, Audit)
  • 정량지표 접근제어 2종(RBAC + SSO 통합 인증) → 공인기관인증, OTP/MFA 추가 시연. OPA 워크로드 정책은 최종 형상
